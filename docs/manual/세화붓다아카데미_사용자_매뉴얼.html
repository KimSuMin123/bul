PART 1 · 수강생

1. 사이트 둘러보기

주소창에 세화붓다아카데미.com을 입력하면 첫 화면이 열립니다. 상단 메뉴에서 About SBA(학회 소개), 강의 과정, 내 강의실로 이동할 수 있습니다. 휴대폰에서는 오른쪽 위 ☰ 버튼을 누르면 메뉴가 열립니다.

첫 화면의 강의 목차 보기를 누르면 강좌 상세 페이지가 열립니다. 수강료, 수강 기간(승인일부터 90일), 전체 차시 목록을 확인할 수 있습니다.

2. 회원가입

  1. 오른쪽 위 회원가입을 누릅니다.
  2. 아이디(영문·숫자 4자 이상)를 입력하고 중복확인을 누릅니다. 이미 있는 아이디면 빨간 글씨로 안내됩니다.
  3. 비밀번호는 영문, 숫자, 기호를 모두 넣어 8자 이상으로 정하고, 한 번 더 입력합니다.
  4. 이름(실명), 생년월일, 휴대전화 번호를 입력합니다. 법명은 있는 경우에만 적으며, 자격증에 이름과 함께 표기됩니다.
  5. 개인정보 수집·이용 동의에 체크해야 회원가입 완료 버튼이 눌립니다.
휴대전화 번호는 한 사람당 한 계정만 가입할 수 있습니다. 수강 신청 안내 문자와 답변 알림 문자가 이 번호로 발송됩니다.

3. 로그인과 비밀번호 분실

아이디와 비밀번호를 입력하고 로그인을 누르면 내 강의실로 이동합니다. 틀리면 "아이디 또는 비밀번호가 일치하지 않습니다."라는 안내가 나옵니다.

비밀번호를 잊었다면 비밀번호 찾기를 누르세요. 교학처(010-4702-0283)에 연락하면 본인 확인 후 관리자가 임시 비밀번호로 초기화해 드립니다.

4. 수강 신청과 수납

  1. 강좌 상세 페이지에서 수강 신청 접수하기를 누릅니다.
  2. 신청이 접수되면 입금 계좌와 금액이 안내됩니다. 신청 직후에는 수납 대기 상태이며, 1~3강은 바로 무료 체험으로 볼 수 있습니다.
  3. 농협 301-0264-3664-41 ([사] 세화불학원)으로 수강료를 입금하거나 교학처에 방문해 수납합니다. 입금자명은 신청자 이름으로 적어 주세요.
  4. 입금 확인과 수강 승인은 매일 오전 10~11시, 오후 6~7시에 진행됩니다. 승인되면 수강 중으로 바뀌고 모든 강의가 열립니다.

5. 내 강의실

상단 내 강의실에서 신청한 강좌의 상태와 진도를 확인합니다.

6. 강의 시청

플레이어 아래쪽 버튼으로 재생·일시정지, 10초 뒤로·앞으로, 음소거, 재생 속도(0.8~1.5배), 전체화면을 조작합니다. 오른쪽 강의 커리큘럼 목차에서 다른 차시로 이동합니다.

순차 학습: 앞 차시를 완강해야 다음 차시가 열립니다. 목차의 자물쇠 표시와 "이전 강의 완강 필요" 문구로 확인할 수 있습니다.

플레이어 아래 강의 개요 및 교안 자료 탭에서 강의 설명과 자료를 볼 수 있습니다.

7. 학습 질의응답(Q&A)

수강 신청을 한 강좌라면 수납 대기(무료 체험) 중에도 질문할 수 있습니다.
  1. 강의 화면에서 학습 질의응답 (Q&A) 탭을 누르고 스님께 질문 올리기를 누릅니다.
  2. 질문 제목과 질문 내용을 적습니다.
  3. 보던 장면에 대해 묻고 싶다면 현재 동영상 재생 위치 첨부하기에 체크합니다. 스님께서 그 시점을 바로 확인하실 수 있습니다.
  4. 다른 수강생이 보지 않았으면 하는 질문은 스님/관리자만 볼 수 있는 비밀글로 등록에 체크합니다.
  5. 질문 등록하기를 누릅니다.

답변이 등록되면 휴대폰으로 알림 문자가 오고, 질문 아래에 스님 답변이 표시됩니다. 전체 질문 / 답변 대기 / 답변 완료 버튼으로 목록을 나눠 볼 수 있습니다. 내 질문은 질문 삭제로 지울 수 있으며, 이때 달린 답변도 함께 지워집니다.

8. 시험과 자격증

강좌의 모든 차시를 100% 완강하면 내 강의실에서 온라인 자격 검정 시험(20문항, 무작위 출제)에 응시할 수 있습니다. 합격하면 자격증이 자동 발급되며, 내 강의실의 정식 자격증 발급 및 출력에서 확인하고 인쇄(PDF 저장)할 수 있습니다. 합격 후에도 성적 갱신이나 복습을 위해 다시 응시할 수 있습니다.

자격증은 본인이 직접 출력하여 사용합니다. 실물 자격증을 따로 받으려면 발급비 10,000원을 농협 301-0264-3664-41 ([사] 세화불학원)으로 입금한 뒤 교학처(010-4702-0283)에 받으실 주소를 알려 주세요. 확인 후 우편으로 발급해 드립니다.
이번 테스트에서는 진도 조작 없이 진행했기 때문에, 전 차시 완강이 필요한 시험 응시 화면은 캡처하지 않았습니다.

9. 자격증 진위 확인

누구나 로그인 없이 자격증 번호로 진위를 확인할 수 있습니다. 주소 끝에 #verify를 붙여 접속하거나 자격증의 QR 코드로 들어옵니다. 번호를 넣고 조회하기를 누르세요.

12. 수강생 관리

검색창에 이름, 휴대전화 번호, 아이디, 회원번호를 입력하면 바로 찾을 수 있습니다. 각 회원 줄 오른쪽의 권한 관리 / 비번 초기화 / 삭제 버튼으로 관리합니다.

회원 직접 등록

전화나 방문으로 접수한 분의 계정을 관리자가 대신 만듭니다. + 신규 사용자 직접 등록을 누르고 인적 사항, 로그인 아이디(추천 ID 생성 사용 가능), 임시 비밀번호를 입력합니다. 강좌 권한 즉시 부여에 체크하면 등록과 동시에 수강 권한과 수납 기록까지 처리됩니다. 맨 아래 개인정보 수집·이용 동의 확인에 체크해야 등록됩니다.

이미 가입된 휴대전화 번호로 등록하면 "요청을 처리하지 못했습니다"라는 안내가 나옵니다. 이 경우 번호가 중복됐는지 먼저 확인하세요.

권한 관리

회원이 강좌별로 어떤 권한을 가졌는지 보고, 강좌를 골라 수강중 / 결제대기 / 수강신청 접수 상태로 바꿉니다.

비밀번호 초기화

새 임시 비밀번호를 입력하고 비밀번호 즉시 변경을 누릅니다. 바뀐 비밀번호는 안전한 방법으로 회원에게 알려 주세요. 기존 비밀번호로는 더 이상 로그인되지 않습니다.

회원 삭제

삭제를 누르면 확인 창이 나옵니다. 삭제하면 그 회원의 수강 이력과 수납 기록도 함께 지워지고, 해당 계정으로는 로그인할 수 없습니다.

13. 수납 승인과 수납 장부

수강 신청이 들어오면 수납 내역 장부 탭에 대기 건수가 표시되고, 신청 줄에 승인 버튼이 생깁니다.

  • 수납 승인: 입금을 확인한 뒤 누릅니다. 회원 상태가 바로 수강 중으로 바뀝니다.
  • 수납 승인 + 기부 영수증 발행: 승인과 동시에 기부금 영수증 대장에 금액을 더합니다.

교학처에 직접 방문해 결제한 경우에는 위쪽 + 대면 수납 등록에서 수강생, 코스, 금액, 결제일, 메모를 입력하고 수납 완료 및 수강 승인을 누릅니다.

전체보기 / 미발행 건만 보기 / 기발행 완료로 장부를 나눠 보고, 전체 엑셀(CSV) 다운로드로 장부를 내려받습니다. 파일은 엑셀에서 한글이 깨지지 않고 열립니다.

14. 기부금 영수증

수납 장부에서 수납 승인 + 기부 영수증 발행이나 + 기부영수증 발행을 누르면 이 대장에 쌓입니다. 같은 전화번호의 기부는 한 줄에 금액이 누적됩니다. 기발행 대장 / 미발행 건만 보기 / 전체 수납·기부 현황으로 나눠 보고, 영수증 보기로 영수증을 확인하며, 엑셀(CSV)로 내려받을 수 있습니다.

15. 강좌·VOD 관리

새 코스 추가

새 코스 추가에서 제목, 부제목, 담당 교수, 수강 기간, 수강료, 썸네일, 자격증 정보를 입력하고 새 코스 등록 완료를 누릅니다.

새 차시 추가

새 차시 추가(또는 상단 + 신규 VOD 차시 등록)에서 소속 코스, 차시 순서, 제목, 설명을 입력합니다. 영상은 파일 직접 업로드 또는 URL 직접 입력 중 하나를 고릅니다.

운영 중인 강좌에 차시를 추가하거나 삭제하면 기존 수강생의 진도율과 완강 여부가 바뀝니다. 학기 중에는 신중하게 변경하세요.

16. 질문에 답변하기

학습 Q&A 탭에 답변 대기 건수가 표시됩니다. 질문 아래 스님 명의로 답변 작성을 누르고 답변을 적은 뒤 답변 게시 완료를 누르면, 질문한 수강생에게 알림 문자가 갑니다. 이미 단 답변은 답변 수정하기로 고칠 수 있고, 부적절한 질문은 질문 삭제로 답변과 함께 지웁니다. 비밀글도 관리자에게는 모두 보입니다.

17. 자격증 발급

시험에 합격해 발급된 자격증 목록을 보여 줍니다. 자격증 인쇄를 누르면 미리보기 창이 열리고, 인쇄 / PDF 저장으로 출력하거나 파일로 저장합니다.

수강생이 실물 자격증 발급비 10,000원을 입금하고 주소를 알려 오면, 입금을 확인한 뒤 자격증을 출력해 우편으로 보내 주세요.

18. 메인 공지

제목과 본문, 이미지(5MB 이하 JPG·PNG·WEBP·GIF), 클릭 링크, 게시 시작·종료 시각을 입력하고 방문자에게 공개에 체크한 뒤 공지 등록을 누릅니다. 시각은 한국 시간 기준이며, 비워 두면 즉시 게시되고 종료 없이 유지됩니다. 등록된 공지는 아래 목록에서 수정, 삭제할 수 있습니다.

공개된 공지는 방문자가 첫 화면에 들어올 때 팝업으로 표시되며, 방문자는 "오늘 하루 보지 않기"로 닫을 수 있습니다.

공지를 삭제해도 첨부한 이미지 파일은 저장소에 남습니다. 필요하면 Supabase Storage의 announcement-images 폴더에서 직접 지워 주세요.

19. 푸시 알림과 앱 설치

관리자 화면 위쪽의 푸시 알림 켜기를 누르고 브라우저 알림을 허용하면, 수강 신청이 들어올 때 알림을 받을 수 있습니다. 알림이 차단돼 있으면 주소창 왼쪽 자물쇠 아이콘에서 알림을 허용으로 바꾸라는 안내가 나옵니다.

관리자 앱(PWA) 설치를 누르면 설치 방법이 안내됩니다. 휴대폰은 브라우저 메뉴의 홈 화면에 추가, PC는 주소창 오른쪽의 앱 설치 아이콘을 사용합니다.
