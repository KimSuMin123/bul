## 정상 동작을 확인한 기능

- 공개: 홈(PC·모바일), About SBA 5개 탭, 강좌 상세(펼치기/접기, 잠긴 차시 안내), 진위 확인(없는 번호/정상 번호), 로그인 실패 안내, 비밀번호 찾기 안내
- 회원가입: 아이디 4자 미만, 중복 아이디, 비밀번호 불일치, 동의 미체크 시 버튼 비활성, 가입 완료
- 수강생: 수강 신청 접수 및 안내 팝업, 대면 수납 안내, 1~3강 무료 체험, 플레이어(재생/일시정지, ±10초, 음소거, 배속, 목차 접기), 강의 개요 탭, 승인 후 공개·비밀 질문 등록(재생 위치 첨부 포함), 답변 확인, 필터, 질문 삭제, 로그아웃
- 관리자: 로그인, 7개 탭 조회, 수납 승인(취소 포함), 수납 승인+영수증, 장부 필터, CSV 다운로드, 대면 수납 등록, 회원 직접 등록(추천 ID), 비밀번호 초기화(이전 비밀번호 로그인 거부, 새 비밀번호 로그인 성공), 권한 관리 창, 회원 삭제(삭제 후 로그인 거부), Q&A 검색·답변 작성·수정·질문 삭제·필터, 공지 등록·이미지 업로드·수정·삭제, 새 코스 추가, URL 차시 추가, 재생 확인, 순차 학습 ON/OFF, 자격증 설정 저장, 차시 삭제, 수료증 인쇄 미리보기, 푸시 알림·PWA 안내

## 테스트하지 않은 항목

- 온라인 시험 응시, 자격증 자동 발급: 전 차시 100% 완강이 필요하며 진도 조작을 하지 않기로 해서 제외
- 문자 실발송: 요청에 따라 스케줄러를 멈춘 상태로 진행
- 동영상 파일 업로드와 영상 교체 실행, 운영 강좌 썸네일·자격증 설정 저장: 운영 강좌에 영향이 있어 창 열기와 입력 확인까지만 진행
- 백업 복원 검증: 백업 파일은 저장했지만 격리 복원 검증은 실패했고, 원인 확인은 권한 설정으로 막힘
